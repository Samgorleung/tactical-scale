## Getting Started

### Prerequisites

- Node.js (v18+)
- npm

### Installation

```bash
npm install
```

### Local Development

```bash
npm run dev
```

The preview will be available at `http://localhost:5173`.

### Production Build

```bash
npm run build
```

Build output is generated into the `dist/` directory.
